# Security policy

CrossPointer is an early-stage open-source project. The Milestone 1 repository contains a Windows input proof and a static controller screen; network transport and pairing are not implemented yet.

Please do not report suspected vulnerabilities publicly when they could expose users. Open a private security report through the repository's GitHub Security tab when available, including affected files, reproduction steps, impact, and a minimal proof of concept. Do not include credentials or personal data.

Until a supported release policy is published, the default supported version is the latest commit on the default branch. Security fixes will be documented in release notes.
